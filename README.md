# Google Cloud 認定の学習記録

> 別案の [Study Light 設計ガイドと部品一覧](app/study-light/README.md) は、Week 1・2 の教材を使った独立した見本です。従来のサイトとその制作基準は引き続き利用できます。

1年で **Professional Cloud Architect（PCA）→ Professional Agentic Architect（PAA）** を目指す。最初の24週間はPCA。ACEの受験は省き、IAM・ネットワーク・デプロイ・監視などの基礎を最初の数週間で実践する。

- [ロードマップ](ROADMAP.md) — 週ごとのテーマ、実践、到達基準
- [チェックリスト](CHECKLIST.md) — できるようになったことを記録
- [進捗](PROGRESS.md) — 前回の実績、詰まった点、次回の作業
- [演習](labs/README.md) — 架空のRAGアプリと第1週の実習
- [公式ケーススタディ](case-studies/README.md) — 4件と分析テンプレート
- `app/` — インタラクティブ学習サイト・**第2週以降のメイン教材（正本）**（制作基準：[app/DESIGN_SYSTEM.md](app/DESIGN_SYSTEM.md)）
- `notes/` — [用語集](notes/glossary.md)、第1週アーカイブノート、必要に応じた補助メモ（第2週以降の週次教材は `app/` に一本化）

学習は週4〜6時間を仮置きする。最初にロードマップの第1週と演習を開く。進捗は日付と裏付けを添えて更新し、未実施は未実施と記録する。

個人リポジトリに置く素材は公開情報、架空データ、自分で書いた一般化した学習記録に限る。端末固有の読書メモはGit管理対象外の `local/` に置く。
